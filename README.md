# تطبيق إدارة أجياد (أندرويد)

تطبيق للموظفين والإدارة فقط. يفتح لوحة إدارة المتجر (`/admin`) داخل التطبيق، ويرنّ الجوال بتنبيه عند:
طلب جديد · ردّ عميل · موافقة العميل على السعر · دفع · طلب تعديل. تسجيل الدخول هو نفسه تسجيل دخول اللوحة (كلمة المرور + رمز المصادقة)،
ولا يصل كل موظف إلا ما تسمح له صلاحياته برؤيته.

الباكج: `com.ajyad.admin` — الحد الأدنى أندرويد 8.0.

## 1) Firebase (مجاني، مرة واحدة)
1. في https://console.firebase.google.com أنشئ مشروعًا (مثلًا `ajyad-admin`).
2. أضِف تطبيق **Android** باسم الباكج `com.ajyad.admin`، ونزّل ملف **`google-services.json`**.
3. من ⚙ إعدادات المشروع ← **Service accounts** ← **Generate new private key** لتنزيل ملف JSON.
   هذا الملف تلصقه أنت في لوحة المتجر (الخطوة 4) ولا ترسله لأحد.

## 2) بناء الـ APK على GitHub (بدون Android Studio)
1. أنشئ مستودعًا **خاصًا (Private)** على GitHub وارفع إليه محتويات هذا المجلد كما هي (بما فيها مجلد `.github`).
2. من المستودع: **Settings ← Secrets and variables ← Actions**:
   - تبويب **Secrets** ← New repository secret باسم `GOOGLE_SERVICES_JSON_B64` وقيمته محتوى `google-services.json` مشفّرًا base64:
     - ويندوز (PowerShell): `[Convert]::ToBase64String([IO.File]::ReadAllBytes("google-services.json"))`
     - ماك/لينكس: `base64 -w0 google-services.json`
   - تبويب **Variables** ← New repository variable باسم `SERVER_URL` وقيمته رابط المتجر مثل `https://odoo.alabbasco.com` (أو دومينك الجديد) بدون `/` في النهاية.
3. من تبويب **Actions** ← **Build APK** ← **Run workflow**. بعد دقائق ينزل في أسفل صفحة التشغيل ملف **`ajyad-admin-apk`**؛ فكّ ضغطه وخذ `app-debug.apk`.
4. انقل الملف إلى الجوال وثبّته (يطلب السماح بالتثبيت من مصدر غير معروف). الإصدارات اللاحقة تُثبَّت فوق السابقة دون حذفها.

> بديل: افتح المجلد في Android Studio، ضع `google-services.json` داخل `app/`، ثم Build ← Build APK.
> إن غيّرت دومين المتجر لاحقًا غيّر المتغير `SERVER_URL` وأعد البناء.

## 3) في لوحة المتجر
1. ارفع تحديث المتجر ونفّذ `php artisan migrate --force` (ينشئ جدول `admin_devices`).
2. **الإعدادات ← تنبيهات الجوال (التطبيق)**: الصق محتوى ملف الـ Service account، فعّل الخيار، احفظ.
3. افتح التطبيق على الجوال، اسمح بالإشعارات، وسجّل الدخول بحسابك. ثم اضغط في اللوحة **إرسال تنبيه تجريبي لجوالي**. يجب أن يرنّ الجوال.

## إن لم يرنّ الجوال
- تأكد أن الإشعارات مفعّلة للتطبيق، وأن قناة **«الطلبات والتنبيهات»** صوتها مفعّل وليست صامتة (إعدادات التطبيق ← الإشعارات).
- أوقف توفير البطارية للتطبيق (سامسونج/شاومي/هواوي: «بدون قيود» أو «تشغيل تلقائي»)، وإلا قد تؤخر الشركة المصنّعة التنبيه.
- وضع «عدم الإزعاج» يكتم الرنين.
- أعد تسجيل الدخول من التطبيق إن غيّرت الجوال أو مسحت بيانات التطبيق.
- الـ cron/الطابور على الاستضافة يجب أن يعمل (التنبيه يُرسل عبر الطابور مع بقية رسائل المتجر).

## للمطوّر
- الرسائل **data-only** عبر FCM HTTP v1؛ يبني `PushService` الإشعار بنفسه بقناة `orders_v1` (رنين الجوال الافتراضي + اهتزاز).
  تغيير الصوت يحتاج رقم قناة جديدًا في `AjyadApp.CHANNEL_ID`.
- تسجيل الجهاز: بعد فتح صفحات `/admin` وأنت مسجّل يُرسل التطبيق الرمز إلى `POST /admin-app/devices` عبر جلسة اللوحة نفسها (كوكي + XSRF)، فلا توجد مفاتيح ولا توكنات إضافية.
- مفتاح التوقيع `app/debug.keystore` ثابت ليتحدّث التطبيق فوق نفسه. المستودع خاص؛ لا تنشره علنًا.
- Gradle 8.7 · AGP 8.5.2 · Kotlin 1.9.24 · JDK 17 · compileSdk 34.
